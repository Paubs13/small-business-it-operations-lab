Before you contact IT

These checks solve a large share of problems and give the technician useful information if they do not.

Can't open an internal page?

  • Check that you are connected to the company network.
  • Check the server status page. If this page loads, the web server is up.
  • Note the exact address you typed and any error message.

Something else is wrong?

  • Write down what you were doing when it happened.
  • Note whether it affects only you or your whole team.
  • Take a screenshot of any error. Do not include passwords.
