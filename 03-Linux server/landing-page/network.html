Network reference

How the lab network is laid out and which commands to run first when something cannot be reached.

Topology

Two VirtualBox adapters with separate jobs: NAT gives the server internet access for updates, and Host-only is the private link between the Windows workstation and the server.

Firewall rules (UFW)

PortServiceAllowed sourceReason
22/tcpSSH192.168.50.0/24Administration from the workstation only
80/tcpHTTP (Nginx)192.168.50.0/24Internal website
all other--Denied by default
 
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow from 192.168.50.0/24 to any port 22 proto tcp
sudo ufw allow from 192.168.50.0/24 to any port 80 proto tcp
sudo ufw enable
sudo ufw status verbose

First checks: "I can't reach the server"

Work from the bottom up: address, then route, then name, then port, then service.

From the Windows workstation (PowerShell)

Get-NetIPConfiguration
Test-Connection 192.168.50.20 -Count 4
Test-NetConnection 192.168.50.20 -Port 80
Test-NetConnection 192.168.50.20 -Port 22
Resolve-DnsName example.com
ssh sysadmin@192.168.50.20

On NS-SRV01 (Ubuntu)

ip -br address
ip route
systemctl status nginx
sudo nginx -t
sudo ufw status verbose
sudo ss -tlnp
sudo tail -n 50 /var/log/nginx/error.log
journalctl -u nginx --since "10 min ago"
